HTML

HTML is used to create the structure of web pages.

CSS

CSS is used to style and layout web pages. არის ტექნოლოგია რომელიმე ვებგვერდების სტილისთვის. მისი საშუალებით შეგიძლია შეცვალო ტექსტის ფერი (color), ფონის ფერი, (background-color), ტექსტის ზომა (font-size), სისქე (font-weight) და გასწორება (text-align). ასევე შეგვიძლი გამოვიყენოთ padding, border, და margin, რომ შევქმნათ სივრცე ელემენტების გარშემო.

JavaScript

JavaScript is used to make web pages interactive.
